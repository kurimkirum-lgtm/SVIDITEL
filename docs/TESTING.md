# Проверка прототипа

## Автоматическая проверка

После коммита GitHub Actions должен запустить workflow **Gradle build**. Успешная сборка означает, что проект компилируется в CI, но ещё не гарантирует, что мод корректно работает в игре.

При успешной сборке workflow сохраняет JAR как артефакт `svidetel-mod` на 14 дней. Его можно скачать на странице запуска Actions в разделе Artifacts.

## Перед запуском в Minecraft

- Использовать именно Minecraft Java Edition 26.3.
- Установить Fabric Loader для 26.3.
- Убедиться, что профиль игры использует Java 25.
- Скачать Fabric API для 26.3.
- Сделать резервную копию мира.
- Положить JAR мода в папку `mods`.

## Что проверять в первом прототипе

- Игра запускается с Fabric API и модом.
- В логах нет ошибки загрузки entrypoint `ru.svidetel.SvidetelMod`.
- В обычном режиме ночью и под землёй редкие сообщения могут появляться только после снижения скрытого рассудка.
- На ярком открытом месте рассудок постепенно восстанавливается.
- После выхода игрока сервер продолжает работать без ошибок.

Скрытые значения пока не имеют пользовательского интерфейса и не сохраняются между перезапусками. Это ожидаемое ограничение прототипа.

## Если сборка упала

Откройте GitHub → Actions → последний запуск **Gradle build** → шаг **Build mod** и скопируйте последние 30–60 строк ошибки. Не нужно присылать токены, пароли или другие секреты.
