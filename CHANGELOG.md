# Журнал изменений

Все изменения относятся к раннему прототипу. Версии до первого проверенного игрового билда не считаются готовыми релизами.

## 0.1.0 — прототип

- Создан проект Fabric для Minecraft Java Edition 26.3.
- Добавлены скрытые параметры рассудка и внимания на время текущего серверного сеанса.
- Рассудок медленно снижается ночью и под землёй, а на ярком открытом месте восстанавливается.
- Спринт постепенно увеличивает скрытое внимание; значение затухает, когда игрок перестаёт шуметь.
- Добавлены редкие атмосферные сообщения при низком рассудке.
- При выходе игрока его временное состояние удаляется.
- Добавлен GitHub Actions workflow для сборки и публикации JAR-артефакта.
- Добавлены документы о поведении Свидетеля и проверке проекта.

## Известные ограничения

- Успешная сборка ещё не подтверждена.
- В игре пока нет сущности Свидетеля, модели, анимаций или особых звуков.
- Параметры не сохраняются после перезапуска сервера.
- Значение внимания пока не запускает события Director AI.
- Атмосферные сообщения используют общий серверный таймер, поэтому точный момент зависит от времени работы сервера.
