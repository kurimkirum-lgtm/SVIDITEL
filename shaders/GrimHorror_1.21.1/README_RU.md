# Grim Horror Shader — Minecraft 1.21.1

Автономный пост-processing шейдерпак для тестирования с Iris / OptiFine.

## Содержимое

- `shaders/composite.vsh` — полноэкранный вершинный проход.
- `shaders/composite.fsh` — постобработка: холодная цветокоррекция, ночное затемнение, виньетка, шум, редкие горизонтальные глитчи, хроматическая аберрация, красная пульсация.
- `shaders.properties` — настройки шейдерпака.

## Установка

1. Скачайте репозиторий или откройте эту папку в GitHub.
2. Для установки как шейдерпака соберите ZIP так, чтобы `shaders.properties` и папка `shaders/` находились в корне архива.
3. Поместите ZIP в `.minecraft/shaderpacks/`.
4. Запустите Minecraft 1.21.1 с Iris или совместимым OptiFine и выберите пакет в настройках шейдеров.

## Важно: статус совместимости

Исходники размещены для тестирования; они не были проверены запуском в Minecraft в рамках этого коммита. Iris и OptiFine могут отличаться по поддерживаемым uniform-переменным, выходным буферам и поведению постобработки. При ошибке загрузки приложите фрагмент `logs/latest.log` с сообщением компилятора GLSL.

## Ограничения

Шейдерпак не может сам определить, что пользовательский монстр находится за спиной игрока, прочитать инвентарь или получить рассудок из мода. Для адаптивных эффектов потребуется модовый интеграционный слой, который передаёт игровые состояния через поддерживаемый графический API или собственный post-processing pipeline. Произвольные uniform-переменные не подключаются автоматически.

## Регулировка интенсивности

В начале `shaders/composite.fsh` можно менять константы `DARKNESS`, `VIGNETTE_STRENGTH`, `GRAIN_STRENGTH`, `GLITCH_STRENGTH`, `CHROMATIC_STRENGTH` и `RED_PULSE_STRENGTH`.
