# СВИДЕТЕЛЬ

> Ты не один. Ты просто ещё не обернулся.

Психологический хоррор-мод для Minecraft Java Edition на Fabric. Проект находится на ранней стадии разработки.

## Статус

- [x] Базовая структура Gradle/Fabric
- [x] Скрытые значения рассудка и внимания на время текущего серверного сеанса
- [x] Редкие атмосферные сообщения
- [ ] Подтверждённая сборка и запуск в игре
- [ ] Сущность Свидетеля и серверный ИИ
- [ ] Замерзание сущности, когда игрок смотрит на неё
- [ ] Преследование вне поля зрения
- [ ] Модель, анимации, звуки и клиентские эффекты
- [ ] Остальные существа, структуры, предметы и сюжет

## Требования

- Minecraft Java Edition 26.3
- Java 25
- Gradle 9.7.1

Отдельно устанавливать Maven не нужно: зависимости скачивает Gradle.

## Сборка в Windows

В корне проекта выполни:

```bat
gradle build
```

Если хочешь создать Gradle Wrapper, выполни:

```bat
gradle wrapper --gradle-version 9.7.1
gradlew.bat build
```

При успешной сборке JAR появится в `build/libs/`.

## Важно

Сборка ещё не подтверждена запуском Gradle и Minecraft. В репозитории пока нет готового JAR, модели моба или клиентских ресурсов. Параметры рассудка и внимания пока хранятся только в памяти текущего сеанса и сбрасываются при перезапуске.
