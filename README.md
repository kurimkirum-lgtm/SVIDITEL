# СВИДЕТЕЛЬ

> Ты не один. Ты просто ещё не обернулся.

Психологический хоррор-мод для Minecraft Java Edition на Fabric. Проект находится на ранней стадии разработки.

## Статус

- [x] Базовая структура Gradle/Fabric
- [x] Скрытые значения рассудка и внимания на время текущего серверного сеанса
- [x] Редкие атмосферные сообщения
- [x] CI-сборка в GitHub Actions с сохранением JAR-артефакта
- [ ] Подтверждённая сборка и запуск в игре
- [ ] Сущность Свидетеля и серверный ИИ
- [ ] Замерзание сущности, когда игрок смотрит на неё
- [ ] Преследование вне поля зрения
- [ ] Модель, анимации, звуки и клиентские эффекты
- [ ] Остальные существа, структуры, предметы и сюжет

## Требования

- Minecraft Java Edition 26.3
- Java 25
- Gradle 9.7.1

Отдельно устанавливать Maven не нужно: зависимости скачивает Gradle.

## Где взять собранный JAR

После успешного запуска workflow открой вкладку [Actions](https://github.com/kurimkirum-lgtm/SVIDITEL/actions), выбери последний запуск **Gradle build** и найди внизу раздел **Artifacts**. Архив `svidetel-mod` содержит собранный JAR и хранится 14 дней.

Если сборка упала, открой шаг **Build mod** и посмотри текст ошибки.

## Локальная сборка в Windows

В корне проекта выполни:

```bat
gradle build
```

Если хочешь создать Gradle Wrapper, выполни:

```bat
gradle wrapper --gradle-version 9.7.1
gradlew.bat build
```

При успешной сборке JAR появится в `build/libs/`.

## Важно

Сборка ещё не подтверждена запуском Gradle и Minecraft. В репозитории пока нет готового проверенного релизного JAR, модели моба или клиентских ресурсов. Параметры рассудка и внимания пока хранятся только в памяти текущего сеанса и сбрасываются при перезапуске.

Следующий приоритет — получить чистую CI-сборку, затем реализовать ИИ Свидетеля и проверить его в игре.
